Live at super-forecast.streamlit.app · FastAPI + Streamlit · GitHub: AndreMendes92/Super-Forecaster · Backend on Render · Frontend on Streamlit Cloud

A full-stack public forecasting web app — upload historical data, pull real government time-series, or use live real estate API data, then forecast 1–12 periods ahead and compare four methods simultaneously. Separated API/UI architecture: FastAPI backend handles all forecasting logic and data source integration; Streamlit frontend handles UX. Two separate free hosting providers — no monolith.
Full-Stack Architecture

📡 StatCan API (Free, No Key)

  • Pulls any public vector ID via WDS API
  • Currently: vector 111955442 = Canada NHPI
  • Index data (Dec 2016 = 100) — % change toggle built in
  • Monthly time series — 12-month seasonality cycle
  • Strip "v" prefix from vector ID on input

🏠 Repliers MLS API

  • Real sold-price stats by city + property type
  • Sandbox key on Render (realistic fake data)
  • Production key (~$199/mo) for real prices
  • CREA HPI prices are realtor-only — no public API
  • CMHC data abandoned — too unreliable

📈 Holt-Winters & ARIMA

  • Holt-Winters: trend + seasonality (best for most)
  • ARIMA: seasonal (monthly/12-cycle) for structure
  • Non-seasonal ARIMA for weekly (52-cycle) stability
  • Both support freq=W and freq=M data

🔧 Deployment

  • Build: pip install -r backend/requirements.txt
  • Start: uvicorn main:app --app-dir backend
  • REPLIERS_API_KEY env var on Render
  • width='stretch' — Streamlit deprecation fixed

Shedula.io · Embedded WFM Forecasting Engine · Growth+ Plan · Python + FastAPI + Erlang C → staffing requirements

Unlike the Super Forecaster (standalone analysis tool), this engine is embedded inside Shedula.io and purpose-built for WFM. It takes historical interval-level call volume data, detects the best statistical method automatically, runs the forecast, then converts output directly into staffing requirements via Erlang C — writing results into the scheduling engine with no manual steps.
WFM Forecasting Pipeline

📈 Holt-Winters

  • Trend detected (slope > threshold)
  • AND weekly seasonality confirmed (autocorr lag 7)
  • Best fit for most contact centres
  • Handles both trend + cyclical patterns

📉 ARIMA

  • Clear trend present, no significant seasonality
  • Statistical time series model
  • Used for monotonic growth/decline

🌊 Seasonal Decomp

  • Strong weekly pattern — no trend slope
  • Separates seasonal from residual noise
  • Best for stable, cyclical contact centre volumes

📏 Moving Average

  • Stable volume — low coefficient of variation
  • No trend, no seasonality signal
  • Flat-projection of last 4 periods

🕐 Forecast History

  • Every forecast auto-saved to forecasts table
  • History pills — click to reload any past run
  • Page loads most recent forecast on mount

⚡ Apply to Staffing

  • One click → writes agents_required per interval
  • Replaces coverage_requirements for queue
  • Scheduling engine immediately picks up new reqs
  • Full horizon (3/6/12mo) applied in one operation
