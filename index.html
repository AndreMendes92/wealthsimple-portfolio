AI & Automation — What I've Actually Built

Wealthsimple's brief is clear: decouple team headcount growth from company growth. That's been my operating principle for three years. I don't add analysts when volume grows — I build systems that absorb growth automatically. Every automation I've shipped exists to remove a human from a loop that shouldn't need one. I sit at the intersection of deep WFM domain knowledge and production engineering — knowing exactly what the business needs and being able to build it without an intermediary is what makes the systems I ship actually work.

RTA Bot — Autonomous Queue Monitoring Agent

Coast Capital Savings. Built a GPT-4 Vision autonomous agent that captures call centre dashboard screenshots via PowerShell Task Scheduler, converts to Base64, sends to the Vision API, extracts calls-waiting and wait-time data per LOB, applies custom threshold logic, tracks alert state (ongoing vs. resolved), and escalates via Microsoft 365 if a breach persists 30+ minutes. Beyond alerting, the bot logs every interval to a historical dataset — enabling trend analysis, pattern detection, and proactive staffing decisions over time. Prior to this, real-time queue monitoring was a dedicated full-time manual role. The bot eliminated that entirely, delivering an estimated $75K in annual savings while producing richer, more consistent data than the manual process ever could.

GPT-4 Vision · PowerShell · M365 · Historical Logging · $75K Saved

Shedula.io — AI Forecasting Engine

Built a smart method detection pipeline that analyses historical interval data for trend (linear regression slope), weekly seasonality (autocorrelation lag 7), and variance (coefficient of variation) — automatically recommends Moving Average, ARIMA, Seasonal Decomposition, or Holt-Winters. Generates plain-English reasoning, applies Erlang C to produce per-interval staffing requirements. Horizons of 3, 6, or 12 months.

Holt-Winters · ARIMA · Erlang C · FastAPI · Python

WFM Assistant Bot — Context-Aware AI Agent (Shedula.io)

Built a floating AI chat agent powered by a Large Language Model (LLM) — meaning the AI understands natural language questions and generates intelligent, context-aware responses, not scripted rule-based replies. Before every message, the bot is injected with live org data: active agents, per-interval coverage gaps, schedule status, and pending time-off requests. This grounds every answer in what's actually happening right now — not static documentation. The bot proposes and executes real actions (create_agent, approve_timeoff, deny_timeoff) via structured ACTION_PROPOSAL blocks with manager confirmation UI before anything fires. DB-backed usage counter with rate limiting.

Claude API · LLM · Live Org Context · Action Execution · React

Hootsuite WFM Intelligence Bot — Claude + Salesforce + Slack

Built using Claude's skills and workflow automation layer to orchestrate multi-source context without requiring manual data pulls.
